# jsc-opencode-dev

Lightweight Docker-based development shell for OpenCode CLI.

This repository provides:

- A container image definition based on Node Alpine.
- A startup script that creates missing local config files and opens an interactive shell.
- A mounted workspace folder for your project files.

## Project Layout

```text
.
├── etc/
│   ├── config/
│   │   └── bashrc
│   └── docker/
│       └── Dockerfile
├── opencode.sh
└── README.md
```

Notes:

- `opencode.sh` can generate `docker-compose.yml` and `opencode.jsonc` automatically if they do not exist.

## Prerequisites

- Docker Engine with Docker Compose (`docker compose` command)
- Linux/macOS shell environment with `bash`

## Quick Start

This project is published with GitHub Pages, [opencode.sh](https://jscoobyced.github.io/jsc-opencode-dev/opencode.sh) is available at:

```text
https://jscoobyced.github.io/jsc-opencode-dev/opencode.sh
```

Download, make executable, and run:

```bash
curl -fsSL https://jscoobyced.github.io/jsc-opencode-dev/opencode.sh -o opencode.sh
chmod +x opencode.sh
./opencode.sh
```

or YOLO mode:

```
curl -fsSL https://jscoobyced.github.io/jsc-opencode-dev/opencode.sh | tee ./opencode.sh | bash
```

## Build the Image

Run from the repository root:

```bash
docker build -t jscdroiddev/jsc-opencode-dev:latest -f ./etc/docker/Dockerfile .
```

## Start an Interactive Dev Session

Run:

```bash
./opencode.sh
```

What `opencode.sh` does:

1. Creates `opencode.jsonc` (if missing) with a default local `llama.cpp` provider configuration.
2. Creates `docker-compose.yml` (if missing).
3. Starts the container in detached mode (`docker compose up -d`).
   a. Alternatively, if it detects a .env file, it will use it to inject environment variables.
4. Opens an interactive shell in the running container (`docker compose exec ... bash`).
5. Stops and removes the container when you exit the shell (`docker compose down`).

## Generated Files

### `opencode.jsonc`

Auto-generated by `opencode.sh` if not present. Update this file to match your model server URL and model names.

### `docker-compose.yml`

Auto-generated by `opencode.sh` if not present. Current default mounts:

- `./project` -> `/home/node/workspace`
- `./opencode.jsonc` -> `/home/node/.config/opencode/opencode.jsonc`

Edit `etc/config/bashrc` to customize:

- Prompt appearance
- Aliases
- Environment variables (`PATH`, `OPENCODE_PATH`, etc.)

The Docker image copies this file to `/etc/bash/bashrc`.

## Common Workflows

### Rebuild after Dockerfile or bashrc changes

```bash
docker build -t jscdroiddev/jsc-opencode-dev:latest -f ./etc/docker/Dockerfile .
./opencode.sh
```

### Enter container manually

```bash
docker compose up -d
docker compose exec jsc-opencode-dev bash
```

### View container logs

```bash
docker compose logs -f jsc-opencode-dev
```

## Troubleshooting

### `service "jsc-opencode-dev" is not running`

Bring the stack up first:

```bash
docker compose up -d
```

### `no configuration file provided: not found`

You are likely not in the repository root. Run commands from this project directory.

### Changes not reflected inside container

If you changed Docker build context files (for example `Dockerfile` or `etc/config/bashrc`), rebuild the image and recreate the container.

## Security Notes

- Do not commit secrets to `opencode.jsonc`.
- Prefer environment-specific overrides for private endpoints or credentials.
